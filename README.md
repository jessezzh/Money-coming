# 记账网页 App Demo

**版本：** v3.0（单文件 · CloudBase 云库版）
**状态：** 演示中
**更新时间：** 2026-10-12

## 用途

以 iPhone 为第一目标的记账网页 App UI 原型。界面参考 Jesse 提供的三张账单统计截图，并按 Apple 风格重新设计为低对比、克制留白、清晰层级与可触摸的原生感交互。

当前版本接入**腾讯云开发 CloudBase 云库**（`records` 集合）：用户名密码登录、两人共用一个账号、账目云端同步持久化；不支持多账本与数据导入导出。

## 入口与运行

- 入口：`index.html`（**单文件**：样式、交互、示例数据全部内联，双击即用）

2026-10-10 起改为纯单文件：放弃 PWA 安装/离线能力，删除 `styles.css` / `app.js` / `manifest.webmanifest` / `sw.js` / `assets/`（删除前已备份至 `冷备份/归档_记账AppDemo单文件化_2026-10-10/`）。

## 已实现

- 移动端单栏总览，桌面打开时模拟 iPhone 纵向画布；仅浅色模式（无暗黑）
- iOS 大字标题导航栏（Money paper）：页面上滑时收拢为居中小标题 + 毛玻璃细线
- 周 / 月 / 年分段切换（玻璃轨道 + 玻璃滑块弹性位移）
- 支出汇总（仅支出，无收入/结余）、分类与月度 / 年度趋势；周视图切换为每日明细
- 趋势图柱 + 折线双形态（同一支出序列）：图例为玻璃开关，点「柱状」「折线」独立显隐，可重叠
- 分类编辑：修改名称、更换图标（SVG 细线图标）、新增与删除分类；分类行也可直接进入编辑
- 底部单一主操作（液态玻璃工具条 + 玻璃蓝主按钮），点击进入新建记录弹层（仅支出）
- 记一笔 / 编辑账目弹层字段：金额、日期（默认今天、自绘月历、过去与未来均可选，字段统一显示完整日期）、分类与子分类、备注；编辑态可改可删
- 明细为单一记录存储（`RECORDS`）按日期区间派生：按日期倒序 + 日期分组，周/月/年/全部各视图只取落在该区间的笔
- 仅前端的新增记录演示；刷新页面后恢复为示例数据
- 适配减少动效、减少透明偏好

## 维护约定

- **设计原则卡（改 UI 前先读）**：①仅浅色；数字纯黑无 ¥ 无红绿 ②层级靠字号字重留白，不靠色彩边框 ③玻璃只给按钮类控件（Liquid Glass），卡片实色扁平 ④间距 8px 节奏，字阶 34/17/15/13 ⑤弹层字段一律「13px 灰标签在上 + 控件在下」，段间 20px、标签与控件间 8px，不加分隔线。
- **弹层玻璃底色**：白弹层上的玻璃按钮底色必须用灰填充（`--fill`）而非 `--glass-bg` 纯白玻璃，否则等于看不见；选中态仍是玻璃蓝。
- UI token 集中在 `index.html` 内 `<style>` 顶部的 `:root`（仅浅色，单值）；分类/明细图标为 JS 内 `ICONS` 注册表的 SVG 细线图标（24 视框 / 1.5 描边）。
- 浏览器要求 Safari 17.5+ / Chrome 123+（backdrop-filter 与 color-mix 依赖）。
- 示例数据和各周期聚合逻辑集中在内联 `<script>`；后续接入 IndexedDB 或 API 时，优先替换数据层，不改变组件结构。
- 不引入第三方 CDN 或构建依赖，方便离线查看与后续 Agent 维护。
- 新增正式版本时更新本文件的版本与“已实现 / 暂未实现”状态。
